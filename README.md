# Ροή ενημερώσεων — Τεχνικό Γραφείο Μουδιώτης

Εβδομαδιαία παρακολούθηση επίσημων πηγών που αφορούν το γραφείο (οχήματα, ρυμουλκούμενα, ΕΧΕΣ, εγκρίσεις τύπου, ταξινόμηση, ΚΤΕΟ):

- ΥΜΕ: Δελτία Τύπου και ενότητες οχημάτων (σελίδες και συνημμένα)
- Διαύγεια: κανονιστικές πράξεις ΥΠΟΜΕ
- Εθνικό Μητρώο Διοικητικών Διαδικασιών: 118 διαδικασίες της λίστας του γραφείου

**Συνδρομή RSS:** https://dimoud.github.io/roi-texniko-grafeio/roi.xml
**Σελίδα ανάγνωσης:** https://dimoud.github.io/roi-texniko-grafeio/

Αρχεία: `roi.xml` (ροή) · `index.html` (σελίδα, από `ftiaxe_selida.py`) · `parakolouthisi_pigon.py` (σενάριο ελέγχου) · `katastasi.json` (αποτυπώματα προηγούμενου ελέγχου) · `roes.opml` (για εισαγωγή σε πρόγραμμα ανάγνωσης RSS).
Ενημερώνεται αυτόματα κάθε Δευτέρα.
